# Classification-Citra-DentalDisease-Algoritma-CNN
 This study develops a Convolutional Neural Network (CNN)-based classification model to diagnose dental pulp diseases through periapical radiographic images. The dataset used consists of 754 images covering three types of lesions, downloaded from Kaggle.
